On the machine, x86-64 Ubuntu 24.04 or later with 16 GiB of memory and 50 GB free, run:

curl -fsSL {{ setup_script_url }} | sudo bash -s -- {{ code }}

It installs what the runner needs, makes the user sc2scala with rootless Docker, so that a bot that breaks out of its container owns nothing of yours, registers the machine, downloads the game's images, about 11 GB, and starts the runner, saying what it does at each step. The machine takes its host name as its name: add --name NAME after the code to choose another, and --replace if one of your machines has that name, when this computer is that machine set up again. Scala is not on PyPI yet, so the script installs the wheel given as sudo SC2SCALA_PACKAGE=/path/to/sc2scala.whl bash.

To read the script before it runs as root, check it against its SHA-256, and run it:

curl -fsSLo setup.sh {{ setup_script_url }}
echo "{{ setup_script_sha256 }}  setup.sh" | sha256sum --check
sudo bash setup.sh {{ code }}
